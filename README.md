# Art Of Motion — Fitness Platform

A full-stack web application for the **Art Of Motion** fitness brand. The platform combines a marketing landing page for various training disciplines (Strength, Stretching, MFR, Gym, Balance Boards) with an interactive scheduling, client booking system, and trainer admin CRM.

## ✨ Features

- **Marketing Landing Page:** Showcases training disciplines and studio information.
- **Client Booking System:** Allows users to view the schedule, book slots, and manage their bookings.
- **Admin CRM:** Provides trainers and administrators with tools to manage templates, slots, and client interactions.
- **Internationalization (i18n):** Multi-language support (English, Ukrainian, Russian).

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router) + React 19
- **Language:** TypeScript
- **Database & Auth:** Supabase (PostgreSQL)
- **Styling:** Tailwind CSS v4
- **UI Components:** Shadcn UI / Radix UI
- **Testing:** Vitest (Unit) & Playwright (E2E)
